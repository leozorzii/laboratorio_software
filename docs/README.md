## Ordem sugerida para estudar

1. Ler os slides em ordem (`aula07` → `aula10`) com o projeto aberto no NetBeans.
2. Passar o [guia de prova](prova-java-banco-de-dados.md) seções 1–9, comparando com o código citado.
3. Revisar a **tabela de erros** (seção 10) — são erros reais que já cometi.
4. Treinar o **checklist** (seção 12): criar uma tabela relacionada nova do zero, sem olhar.
5. Responder as perguntas teóricas (seção 11) em voz alta.
